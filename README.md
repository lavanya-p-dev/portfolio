# Personal Portfolio Website

A responsive personal portfolio website built with **React.js** to showcase my professional profile, technical skills, projects, experience, and career journey. Integrated **EmailJS** to enable visitors to contact me directly through the portfolio.

🔗 **Live Demo:** [Pureddy Lavanya's Portfolio](https://portfolio-lavanyap.vercel.app/)

### 🛠️ Technologies

**React.js · JavaScript · HTML5 · CSS3 · Bootstrap · EmailJS**
